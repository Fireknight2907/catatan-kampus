# Catatan Kampus

Aplikasi mobile Catatan Kampus berbasis Vue 3, Ionic Framework, dan Capacitor.

## Teknologi

- Vue 3
- Ionic
- Capacitor

## Struktur Utama

- `src/views/` untuk halaman
- `src/components/` untuk komponen yang dipakai ulang
- `src/router/` untuk pengaturan URL dan halaman

## Persyaratan

- Node.js LTS
- npm

## Menjalankan Project

```bash
npm install
npx ionic serve
```

## Status Awal

Halaman Hello World sudah dapat dijalankan di browser.
